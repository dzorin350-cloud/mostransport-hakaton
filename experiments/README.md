# Журнал экспериментов

Здесь лежат скрипты исследования, из которых выросла итоговая модель: EDA, валидация, подбор гиперпараметров, проверка внешних
данных, годовая модель, проверки функций сервиса. Результаты сведены в [docs/TESTS.md](../docs/TESTS.md) и
[ARCHITECTURE.md](../ARCHITECTURE.md) §6–7.

**Это журнал, а не рабочий код.** Скрипты запускались по ходу работы на машине разработчика: часть путей к данным
(`raw.parquet` из исходных `train.csv` / `test.csv` ≈ 10 ГБ, промежуточные файлы) абсолютные и без правки не сработает.
Рабочий код модели — [`model/code/`](../model/code/) (воспроизводит сабмит байт в байт, см. [docs/MODEL.md](../docs/MODEL.md)),
рабочий код сервиса — [`service/`](../service/).

|---|---|---|---|
