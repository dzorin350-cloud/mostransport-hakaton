# Модель: артефакты, обучение, прогноз

**Коротко.** Итоговая модель даёт **WAPE-score 0,89136** на лидерборде (ноябрь–декабрь 2025, 14 640 строк
«маршрут × дата × час»). Прогноз = уровень маршрута × форма дня × сезонный множитель. Как это работает —
[ARCHITECTURE.md](../ARCHITECTURE.md), раздел 2.

## Где что лежит

| Что | Где |
|---|---|
| Обученные модели для сервиса | [`service/engine/artifacts/`](../service/engine/artifacts/): 10 моделей CatBoost, `config.json` с параметрами |
| Код обучения | [`model/code/`](../model/code/): `build_grid.py` — сетка из данных, `clean.py` — очистка и сезонность маршрута, `model.py` — календарь и признаки, `pipe.py` — CatBoost и профиль, `best_params_final.json` — все параметры |
| Обучение моделей сервиса | [`service/engine/train.py`](../service/engine/train.py) |
| Прогноз в сервисе | [`service/engine/core.py`](../service/engine/core.py) |
| Прогноз без сервиса | [`model/code/forecast.py`](../model/code/forecast.py) |
| Отправленный сабмит | [`model/submission.csv`](../model/submission.csv), [`model/submission.md5`](../model/submission.md5) |
| Исходные данные | [`labels/`](../labels/): почасовые посадки январь–октябрь 2025 |

## Запуск

Нужны Python 3.12+ и `pip install -r requirements.txt` (catboost, pandas, numpy, pyarrow) либо Docker.

```bash
cd model/code
python build_grid.py                  # данные → почасовая сетка
python final.py                       # обучение и прогноз → model/output/submission.csv (совпадает с сабмитом байт в байт)
python forecast.py --start 2025-11-01 --end 2026-10-31 --out ../output/forecast.csv   # любой период до 12 месяцев
```

В Docker из корня репозитория: `docker build -t tram-model . && docker run --rm tram-model`.
Переобучить модели сервиса: `python -m service.engine.train` из корня, затем `docker compose up -d --build` в `service/`.

## Параметры

| Часть | Значение |
|---|---|
| Уровень | средние посадки в сутки за 56 дней очищенной истории |
| Очистка | день заменяется, если отличается от обычного для такого дня больше чем в 1,5 раза или если за неделю доля маршрута в сети сдвинулась больше чем на 15 % |
| CatBoost | цель — доля часа от уровня; 800 итераций, глубина 8, параметры подобраны Optuna; 5 моделей на базовых признаках и 5 с длиной светового дня |
| Признаки | маршрут, час, день недели, выходной, праздничный будний день, дни до и после выходных, длина светового дня |
| Смесь с профилем | профиль — медиана за 4 недели; доля CatBoost: будни 60 %, выходные 50 %, ночь 40 %; праздничные будни — 60 % CatBoost и 40 % профиля воскресенья |
| Сезонность | ноябрь ×0,985, декабрь ×1,052 к октябрю по городу, с поправкой на чувствительность маршрута |

|---|---|---|

## Проверка

| Проверка | Результат |
|---|---|
| Бэктесты «обучение до даты → прогноз на 2 месяца»: мар–апр / май–июн / июл–авг / сен–окт | 0,849 / 0,871 / 0,842 / 0,879 |
| Реальный октябрь 2025 в сервисе, прогноз обновляется раз в неделю | 0,908 (без обновлений 0,898) |
| Прогноз сервиса против сабмита | разница 0,008 % |
| Воспроизводимость | `final.py` даёт сабмит байт в байт, в том числе в Docker |

Гиперпараметры CatBoost подбирались только на данных до конца августа. Новые части модели и веса смеси проверялись
на всех четырёх периодах и брались, только если не ухудшали ни один из них. Фактические данные
ноября–декабря 2025 года (посадки, погода, городская статистика) не использовались.
