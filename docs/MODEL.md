# ML-модель: артефакты, код обучения и инференса, запуск

**Итоговая модель — WAPE-score 0,89136 на лидерборде** (прогноз 01.11–31.12.2025, 14 640 строк «маршрут × дата × час»).
Как модель устроена и почему так — [ARCHITECTURE.md](../ARCHITECTURE.md); все проверки — [TESTS.md](TESTS.md).

**Прогноз = уровень маршрута × форма дня × сезонный множитель месяца (свой для маршрута).**
Уровень — средние посадки маршрута в сутки за последние 56 дней; форма дня — доли часов от CatBoost (два набора по 5 моделей: базовый и с длиной светового дня) в смеси
с профилем последних 4 недель (медиана); сезонный множитель — отношение пассажиропотока трамвая Москвы в месяце прогноза к базовому
месяцу за прошлые годы (data.mos.ru). Обучение идёт на истории, очищенной от перекрытий и разовых сбоев.

## Запуск

Нужен Python 3.12+ и `pip install -r requirements.txt` (catboost, pandas, numpy, pyarrow), либо Docker.

**1. Воспроизвести отправленный сабмит (байт в байт):**
```bash
cd model/code
python build_grid.py            # labels/ → data/grid.parquet
python final.py              # обучение 5 CatBoost + прогноз → model/output/submission.csv
md5sum ../output/submission.csv   # совпадает с model/submission.md5
```

**2. Прогноз на произвольный период (до 12 месяцев вперёд):**
```bash
cd model/code
python forecast.py --start 2025-11-01 --end 2026-10-31 --out ../output/forecast.csv            # по встроенным внешним данным
python forecast.py --start 2025-11-01 --end 2025-12-31 --refresh                                # предварительно обновить календарь и сезонность
```
То же в Docker из корня репозитория: `docker build -t tram-model . && docker run --rm tram-model`.

**3. Переобучить модели сервиса** (после новых данных или появления маршрута):
```bash
python -m service.engine.train   # из корня репозитория; модели и config.json → service/engine/artifacts/
```
Затем пересобрать сервис: `cd service && docker compose up -d --build`.

**4. Модель в работе (веб-сервис):** `cd service && docker compose up -d --build` — сервис сам применяет модель
к истории, сам скачивает календарь и сезонность, строит прогноз на 12 месяцев и пересчитывает его при поступлении
новых данных. Инструкция для жюри — [JURY.md](JURY.md).

## Параметры модели

| Блок | Значение |
|---|---|
| CatBoost | цель — доля часа от скользящего 42-дневного уровня; RMSE, 800 итераций, глубина 8, lr 0,049, l2 12, Bernoulli 0,59; 5 запусков с разными seed |
| Признаки | маршрут, час, день недели, выходной, праздничный будний день, рабочий день до / после выходных (календарь isdayoff.ru) |
| Смесь формы дня | доля CatBoost: будни 0,6, выходные 0,5, ночные часы (22–5 ч) 0,4; праздничные будни — 0,6·CatBoost + 0,4·воскресный профиль за 8 недель |
| Уровень маршрута | 56 дней очищенной истории |
| Очистка | дни вне ×1,5 от медианы того же типа дня, недели со сдвигом доли маршрута в сети > 15 % → замена «нормальным» значением (168 маршруто-дней) |
| Сезонность | ноябрь ×0,9846, декабрь ×1,0518 к октябрю (среднее 2019, 2021–2024; 2020 исключён); для маршрута — множитель в степени 1 + 0,6·(β − 1), β — чувствительность маршрута к сезонности города по месяцам 2025 |
| Маршрут 5 | в данных нет посадок → прогноз 0 |
