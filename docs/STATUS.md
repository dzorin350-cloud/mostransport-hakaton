## Главная мысль

Модель — на максимуме баллов (WAPE-score 0,88399). В отдельной ветке `feature/dispatcher-reliability` диспетчерская логика
доведена до API и рабочего интерфейса: план выпуска, действия по алертам и сценарный пересчёт. Перед сдачей остаются проверка
бизнес-эффекта на факте, финальная проверка развёртывания и командные задачи ниже. В `main` эти изменения ещё не слиты.

## Что уже готово

- **Модель v7:** WAPE-score 0,88399 (верхняя корзина), честная валидация, воспроизводимость байт в байт.
- **Движок:** сам применяет модель и скачивает внешние данные (календарь, сезонность, погода), принимает новые факты через API
  и сам пересчитывает прогноз; архив версий прогноза; `/monitor/accuracy` — факт против прогноза (реальный октябрь: 0,9038 с еженедельными
  обновлениями против 0,8952 без них).
- **Для диспетчера (API):** загрузка вагонов и рекомендация выпуска `/fleet`, коридор 80 % (`lo`/`hi`), режим «Сейчас» с демо-временем
  `/now`, алерты `/alerts`, подсказки, оценочная разбивка по остановкам `/stops`, `/forecast/stops`.
- **Погода:** поправка в дни сильного дождя по прогнозу на 16 дней; на стенде демо по архиву.
- **Доступ и эксплуатация:** авторизация (OAuth2 + JWT), демо-аккаунт `demo` / `demo2025`, ошибки на русском, образы amd64 и arm64 (файлы).
- **Производительность:** прежний профиль только прогноза ≈ 995 RPS; новый смешанный профиль диспетчера — ≈ 395 RPS, p95 72 мс,
  CPU ~60–64 %, RAM ≈ 930 МиБ, swap 0 (4 vCPU, 10 минут, ≈ 236 тыс. запросов, 0 ошибок).
- **Документация:** для жюри, тесты, внешние данные, область применимости, спецификация для фронтенда.

## Боль диспетчера → что сделано → ограничения

| Боль диспетчера | Что сделано | Ограничение / следующий шаг |
|---|---|---|
| **Узнаёт о давке по факту и по жалобам, а не заранее** | прогноз маршрут × час; `/alerts` показывает действие, срок реакции и пассажиров под риском | уверенность эвристическая, решение диспетчера нужно проверять |
| **Выпуск вагонов — по нормативу и опыту** | `/fleet` и `/plan`: рекомендации на завтра / неделю, разница с нормой, причины, XLSX для депо | план оценочный, не утверждённое расписание |
| **Пустые вагоны в межпик** | план показывает, где можно снять или добавить вагоны | фактический эффект на переполненность не посчитан (п. 6) |
| **Нетипичные дни** (переносы праздников, рабочие субботы, дождь, ремонты) | календарь и прогноз погоды; коэффициент сценария пересчитывает `/fleet`, `/plan`, `/alerts` | коэффициент — ручная гипотеза, не причинная модель конкретного события |
| **Можно ли верить цифре** | коридор 80 %, `/monitor/accuracy`, качество на экране диспетчера, уверенность в алерте | уверенность пока эвристическая; нужна калибровка по фактам |
| **Где на маршруте давка** | оценочная разбивка по остановкам и направлениям | точность не проверяема — подписывать как оценку |
| **Никто не проверяет, помогли ли рекомендации** | журнал «принял / отклонил / отложил» и отчёт по решениям | нет подтверждения исполнения и доказанного причинного эффекта |
