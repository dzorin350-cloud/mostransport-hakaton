# Отчёт: годовая модель и бэкенд с движком прогноза (26.09.2026)

Итоговая модель для ноября–декабря 2025 на момент отчёта не менялась (лидерборд 0,88399). 27.09 она обновлена — ансамбль с длиной
светового дня, сезонность маршрута и веса смеси, лидерборд 0,89136 (`docs/TESTS.md` §1.4); цифры ниже относятся к версии на 26.09.

## 1. Годовая модель (январь–октябрь 2026)

Все проверки — «обучение до даты → прогноз вперёд», только данные до даты старта.

### 1.1 Рост: зашит в множители или явный
Город (месячный пассажиропоток трамвая, 34 стартовых месяца 2022–2024, горизонт 1–12 мес.), скор 1 − WAPE:

| Метод | Все старты | Старты в октябре |
|---|---|---|
| **Текущий (итоговая модель): множители, рост зашит** | 0,9236 | **0,9496** |
| Индекс сезонности + явный рост | 0,9266 | 0,9324 |
| Индекс сезонности без роста | 0,9156 | — |
| Среднее текущего и явного роста | **0,9282** | 0,9450 |

Наши маршруты по часам (старты 28.02, 31.03, 30.04.2025, прогноз до октября): текущий **0,8575**, явный рост 0,8447, среднее 0,8555.

**Вывод: не получилось.** Город и маршруты дают противоположные ответы, устойчивого выигрыша нет. Оставлены множители итоговой модели.

### 1.2 Сезонная форма дня (распределение по часам зависит от месяца)
Та же проверка на маршрутах по часам:

| Вариант | Скор |
|---|---|
| Как в итоговой модели (форма не зависит от месяца) | 0,8575 |
| Потолок: фактическая форма того же месяца (оракул) | 0,8746 |
| **Реалистично: форма месяца по другой половине месяца, доля 0,5** | **0,8691 (+1,2)** |
| то же, доля 0,75 | 0,8705 (+1,3) |

Прирост есть на каждом горизонте (1–8 месяцев). **Вывод: получилось, внедрено** с осторожной долей 0,5: в 2026 году форма месяца берётся из того же месяца 2025 года.

### 1.3 Итоговая годовая модель
прогноз = уровень маршрута × форма дня (CatBoost + профиль, **смешанная с формой того же месяца год назад**) × сезонный множитель месяца.

- Ноябрь–декабрь 2025: как в итоговой модели (формы «год назад» нет).
- Январь–октябрь 2026: суточные итоги те же, меняется распределение по часам. Пример: маршрут 17, будни июля — утренний пик ниже (8:00: 4 409 вместо 4 509), вечерний позже (19:00: 3 076 вместо 2 929).

### 1.4 Что не получилось или не проверено
- Проверить полный год на маршрутах нельзя: история маршрутов — 10 месяцев.
- Сезонность по отдельным маршрутам не внедрена: нет прошлых лет по маршрутам, проверить нечем.
- Рост за год (октябрь 2026 ≈ +11 % к октябрю 2025) зашит в множители; при смене тренда годовой прогноз сместится.

## 2. Бэкенд: сервис сам применяет модель

Код — `service/engine/`, подробности — `service/engine/README.md`, все прогоны и тесты — `docs/TESTS.md`.

- **Применение модели:** фоновый процесс в контейнере загружает 5 моделей CatBoost (обучены офлайн), читает историю валидаций, чистит её, считает уровни и профиль, строит почасовой прогноз на 12 месяцев вперёд от даты данных, включая годовую форму дня. Готовые CSV-прогнозы удалены.
- **Внешние данные сервис скачивает сам:** календарь isdayoff.ru (проверено: live), сезонность data.mos.ru (только месяцы ≤ даты данных). Если источник недоступен — кэш, затем встроенная копия; что использовано, видно в `/model/info`.
- **Новые данные:** новый файл истории → через 33 с все воркеры отдают прогноз с новой датой данных и сдвинутым горизонтом, без перезапуска.
- **Любые диапазоны** внутри 12 месяцев, детализация час/день/неделя/месяц, суммы согласованы; за пределами горизонта — понятная ошибка 400.

| Проверка | Результат |
|---|---|
| Ноябрь–декабрь против `submission.csv` | совпадает до 0,0023 % (297 посадок на 12,8 млн; праздничные блоки по isdayoff вместо ручного списка итоговой модели) |
| Пересчёт прогноза на 12 месяцев | ≈ 4,5 с + загрузка данных (до 21 с, если data.mos.ru не отвечает) |
| Нагрузка 4 vCPU, 200 польз. | **1 282 RPS, p95 68 мс** (было на CSV: 885 RPS, p95 190 мс), 0 ошибок |
| Нагрузка 4 vCPU, 400 польз. | 1 210 RPS, p95 310 мс, 0 ошибок |
| Нагрузка 2 vCPU, 200 польз. | 890 RPS, 0 ошибок (было 610) |
| Память контейнера | ≈ 0,9 ГБ из 4 ГБ |

Ограничение: data.mos.ru недоступен с тестовой машины (закрыт для зарубежных адресов), поэтому сезонность в тестах — встроенная копия. В российском контуре не проверено.
